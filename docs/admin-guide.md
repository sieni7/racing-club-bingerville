# Guide Administrateur - Racing Club de Bingerville

## 1. Introduction
Bienvenue dans le guide administrateur. En tant qu'administrateur, vous avez accès à l'ensemble des fonctionnalités du tableau de bord. Ce guide vous accompagne dans la gestion quotidienne de la plateforme.

## 2. Gestion des utilisateurs
### 2.1 Créer un compte
- Rendez-vous sur la page **Joueurs** ou **Utilisateurs**.
- Cliquez sur **Nouveau** pour ajouter un profil.
- Remplissez les informations obligatoires (Nom, Email, etc.).

### 2.2 Assigner un rôle (ADMIN, STAFF, MEMBER, JOUEUR, PARENT)
- Depuis la fiche utilisateur, modifiez le champ **Rôle**.
- Les rôles définissent les droits d'accès : 
  - **ADMIN** : Tous les droits.
  - **STAFF** : Gestion des matchs et des joueurs.
  - **JOUEUR** : Accès à son profil.
  - **PARENT** : Suivi de ses enfants.

### 2.3 Désactiver un compte
- Allez sur le profil de l'utilisateur concerné.
- Passez le statut sur **INACTIF**.

## 3. Supervision
### 3.1 Tableau de bord administrateur
- L'accueil offre une vue d'ensemble (Insights, Matchs à venir).
- Le **Command Center (Ctrl+K)** permet une navigation rapide vers toutes les ressources.

### 3.2 Logs d'activité
- Toutes les actions critiques sont enregistrées.

### 3.3 Statistiques globales
- La page **Statistiques** rassemble les indicateurs clés de performance du club.

## 4. Maintenance
### 4.1 Sauvegarde des données (Supabase)
- Les données sont sécurisées sur Supabase. Aucune intervention manuelle n'est requise.

### 4.2 Gestion du stockage (photos)
- Les photos des joueurs sont stockées dans le Storage Supabase.
