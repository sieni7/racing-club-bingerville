# Guide Staff (Entraîneurs) - Racing Club de Bingerville

## 1. Gestion des joueurs
### 1.1 Ajouter un joueur
- Cliquez sur **Nouveau joueur** depuis la liste des joueurs.
- Renseignez les informations de base.

### 1.2 Modifier les informations
- Cliquez sur l'icône **Éditer** à côté du nom d'un joueur pour mettre à jour ses données.

### 1.3 Upload photo
- Utilisez le champ de téléchargement dans le formulaire du joueur.

### 1.4 Statut (ACTIF / BLESSÉ / SUSPENDU)
- Mettez à jour ce statut pour gérer les indisponibilités de l'effectif.

## 2. Gestion des matchs
### 2.1 Créer un match
- Depuis la page **Matchs**, cliquez sur **Nouveau match**.

### 2.2 Programmer la date, heure, adversaire
- Sélectionnez le lieu (Domicile / Extérieur) et définissez la date de la rencontre.

### 2.3 Définir la compétition
- Indiquez s'il s'agit d'un match de championnat, amical ou de coupe.

## 3. Composition d'équipe
### 3.1 Sélection titulaires / remplaçants
- Depuis la **Feuille de match**, ajoutez les joueurs convoqués.
- Marquez-les comme Titulaire ou Remplaçant.

### 3.2 Désigner capitaine
- Attribuez le brassard au joueur choisi dans la composition.

## 4. Événements de match
### 4.1 Ajouter un but
- Enregistrez les buteurs et passeurs dans la feuille de match.

### 4.2 Ajouter un carton jaune/rouge
- Renseignez les avertissements pour alimenter les statistiques de discipline.

### 4.3 Gérer les remplacements
- Indiquez les entrées et sorties en cours de jeu.

## 5. Consultations
### 5.1 Calendrier des matchs
- Utilisez la vue Calendrier pour visualiser le programme du mois.

### 5.2 Statistiques joueurs
- Consultez la page **Statistiques** pour repérer les joueurs en forme.
