# DESIGN SYSTEM - RACING CLUB BINGERVILLE

## 1. Palette de couleurs

| Rôle | Couleur | Code | Usage |
|------|---------|------|-------|
| **Primary** | Bleu Racing | `#1E3A5F` | Header, boutons principaux |
| **Primary dark** | Bleu nuit | `#0F2440` | Dark mode, hover |
| **Primary light** | Bleu clair | `#2B4A7A` | Accents subtils |
| **Secondary** | Or | `#D4AF37` | Accents, badges, médailles |
| **Secondary dark** | Or sombre | `#B8960F` | Hover accents or |
| **Secondary light** | Or clair | `#E2C265` | Éléments décoratifs |
| **Accent Success** | Vert sport | `#2E7D32` | Succès, validation |
| **Accent Danger** | Rouge | `#C62828` | Suppression, erreurs |
| **Accent Warning** | Orange | `#ED6C02` | Alertes, A Venir |
| **Accent Info** | Bleu vif | `#0288D1` | Informations générales |

## 2. Typographie

- **Titres (H1-H6)** : `Montserrat`, sans-serif
- **Corps du texte** : `Open Sans`, sans-serif

## 3. Espacements (8px scale)

- `18` = 4.5rem (72px)
- `88` = 22rem (352px)

## 4. Effets & Ombres

- **Soft shadow** : `0 10px 25px -5px rgba(0, 0, 0, 0.1)` (Card base)
- **Soft shadow large** : `0 20px 30px -10px rgba(0, 0, 0, 0.15)` (Card hover)
- **Transition** : 200ms / 300ms ease-in-out

## 5. Composants UI (Base)
- `Button` : Primary, Secondary, Danger, Success
- `Card` : Default, Hoverable
- `Badge` : Primary, Secondary, Success, Danger, Warning
